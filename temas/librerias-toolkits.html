¿Qué es una librería y qué es un toolkit?

Una librería (o biblioteca) es un conjunto de código ya escrito y probado que resuelve una tarea específica, y que nosotros llamamos desde nuestro programa cuando lo necesitamos. Por ejemplo, una librería para hacer peticiones HTTP o para cargar imágenes.

Un toolkit (o kit de herramientas) es un conjunto más amplio de librerías, componentes, herramientas y utilidades que sirven para construir aplicaciones completas o una parte grande de ellas, como toda la interfaz gráfica. Normalmente incluye componentes visuales, documentación, compiladores o emuladores.

Diferenciar toolkits para la programación móvil

Los toolkits se pueden clasificar según si generan apps nativas (una sola plataforma) o multiplataforma (un mismo código para Android y iOS):

ToolkitTipoLenguajeCaracterísticas
Android SDK + JetpackNativo AndroidKotlin / JavaHerramientas oficiales de Google; acceso total al hardware; se usa con Android Studio.
Jetpack ComposeNativo Android (UI)KotlinInterfaces declarativas con funciones @Composable; reemplaza poco a poco a los layouts XML.
iOS SDK (UIKit / SwiftUI)Nativo iOSSwiftHerramientas oficiales de Apple; se usa con Xcode en una Mac.
FlutterMultiplataformaDartDe Google; dibuja su propia interfaz con widgets; un solo código para Android, iOS, web y escritorio.
React NativeMultiplataformaJavaScript / TypeScriptDe Meta; usa componentes nativos reales; ideal si ya se sabe React.
.NET MAUIMultiplataformaC#De Microsoft; sucesor de Xamarin.Forms; apps para Android, iOS, Windows y macOS.
Kotlin MultiplatformMultiplataformaKotlinComparte la lógica entre plataformas y permite interfaz nativa o con Compose Multiplatform.
Ionic + CapacitorHíbridoHTML, CSS, JSApps hechas con tecnologías web dentro de un contenedor nativo.
📌 Los toolkits nativos dan el mejor rendimiento y acceso a todas las funciones del sistema, mientras que los multiplataforma ahorran tiempo porque se escribe un solo código para varias plataformas.
