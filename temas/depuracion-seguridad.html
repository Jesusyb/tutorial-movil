🛡️ Depuración y seguridad

Cómo encontrar errores en una app y cómo protegerla a ella y a sus usuarios.

¿Qué es la depuración y la seguridad?

La depuración (en inglés debugging) es el proceso de encontrar, analizar y corregir los errores (bugs) de un programa. Incluye ejecutar la app paso a paso, revisar los valores de las variables, leer los mensajes de error y medir el rendimiento.

La seguridad en aplicaciones móviles es el conjunto de prácticas y mecanismos para proteger la app, los datos del usuario y la comunicación con los servidores contra accesos no autorizados, robo de información o modificaciones maliciosas.

Buenas prácticas de seguridad

  • Usar siempre HTTPS para comunicarse con los servidores.
  • No guardar contraseñas ni claves de API escritas directamente en el código.
  • Guardar datos sensibles de forma cifrada, usando el Android Keystore o el Keychain de iOS.
  • Pedir solo los permisos necesarios.
  • Validar los datos que escribe el usuario para evitar inyecciones SQL.
  • Ofuscar el código al publicar (R8 / ProGuard en Android).
  • Mantener las librerías actualizadas.
  • Revisar la guía OWASP Mobile Top 10, que lista los riesgos más comunes en apps móviles.

Herramientas de depuración en el entorno de desarrollo

Android Studio

Herramienta¿Para qué sirve?
Depurador (Debugger)Poner breakpoints, ejecutar línea por línea (step over / step into), ver y cambiar variables mientras corre la app.
LogcatVer los mensajes del sistema y los que escribimos con Log.d(), Log.e(), etc.; filtrar por app o nivel.
Layout InspectorRevisar la jerarquía de vistas y componentes de Compose de la pantalla en tiempo real.
Android ProfilerMedir el uso de CPU, memoria, red y energía para encontrar fugas de memoria o partes lentas.
App InspectionDatabase Inspector (ver y editar la base de datos SQLite/Room), Network Inspector (ver las peticiones) y Background Task Inspector (ver los trabajos de WorkManager).
Emulador (AVD)Probar la app en diferentes dispositivos y versiones de Android, y simular ubicación, batería o sensores.
ADB (Android Debug Bridge)Herramienta de línea de comandos para instalar apps, ver logs y controlar el dispositivo.
LintAnaliza el código y avisa de errores, problemas de rendimiento, accesibilidad o seguridad.

Otros entornos

  • Xcode (iOS): depurador LLDB, Instruments (rendimiento y memoria), View Debugger y la consola.
  • Flutter: Flutter DevTools (inspector de widgets, rendimiento, red) y hot reload.
  • React Native: React Native DevTools y las herramientas de desarrollador de Chrome.
  • Firebase Crashlytics: reporta los errores que les ocurren a los usuarios con la app ya publicada.
Ejemplo: usar Logcat y un breakpoint
kotlin
private const val TAG = "MainActivity"

fun calcularPromedio(calificaciones: List<Double>): Double {
    Log.d(TAG, "Calificaciones recibidas: $calificaciones")

    if (calificaciones.isEmpty()) {
        Log.e(TAG, "La lista está vacía")   // aparece en rojo en Logcat
        return 0.0
    }

    val promedio = calificaciones.sum() / calificaciones.size   // <- aquí se puede poner un breakpoint
    Log.i(TAG, "Promedio: $promedio")
    return promedio
}
