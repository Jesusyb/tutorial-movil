🎬 Recursos multimedia

Imágenes, audio, video y animaciones dentro de una aplicación móvil.

Contenido

  2. Tipos de recursos multimedia en la programación móvil
  3. Elementos de la estructura del proyecto donde se guardan

Definición

Los recursos multimedia son todos los elementos que combinan distintos medios para comunicar información o mejorar la experiencia del usuario: imágenes, sonidos, videos, animaciones y gráficos. En una aplicación móvil se usan para hacerla más atractiva, más fácil de entender y más interactiva.

Tipos de recursos multimedia en la programación móvil

🖼️ Imágenes

Pueden ser de mapa de bits (PNG, JPG, WebP) o vectoriales (SVG, Vector Drawable en Android, PDF vectorial en iOS). Las vectoriales se ven bien en cualquier tamaño de pantalla. Se usan para íconos, fondos, fotos y logotipos.

🔊 Audio

Formatos como MP3, AAC, OGG y WAV. Se usan para música, efectos de sonido, notificaciones, mensajes de voz y podcasts.

🎥 Video

Formatos como MP4 (H.264/H.265) y WebM. Puede ser un video guardado en la app o transmitido por internet (streaming). Ejemplo: tutoriales, anuncios, videollamadas.

✨ Animaciones

Movimientos o transiciones de los elementos: animaciones de propiedades (mover, rotar, escalar, cambiar transparencia), GIF animados, animaciones vectoriales y archivos Lottie (animaciones en formato JSON exportadas desde After Effects).

📊 Elementos visuales dinámicos

Contenido que cambia en tiempo real según los datos o las acciones del usuario: gráficas, barras de progreso, mapas interactivos, transiciones entre pantallas, dibujos en Canvas y efectos al tocar la pantalla.

Elementos de la estructura del proyecto donde se guardan

Cada plataforma tiene carpetas específicas para los recursos. En Android:

Carpeta¿Qué se guarda?
res/drawable/Imágenes (PNG, JPG, WebP) y gráficos vectoriales XML.
res/mipmap/Ícono de la aplicación en diferentes resoluciones (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi).
res/raw/Archivos de audio y video que se leen tal cual (R.raw.cancion).
res/anim/ y res/animator/Definiciones XML de animaciones.
res/font/Fuentes tipográficas personalizadas.
assets/Archivos con su estructura original de carpetas (HTML, JSON de Lottie, bases de datos precargadas).

En iOS los recursos se guardan en el catálogo Assets.xcassets (imágenes, íconos, colores). En Flutter se ponen en una carpeta assets/ y se registran en el archivo pubspec.yaml.

Componentes de software para usar recursos multimedia

  • ImageView / Image (Compose): muestran imágenes en la interfaz.
  • Glide, Coil y Picasso: librerías para cargar imágenes de internet con caché.
  • MediaPlayer: reproduce audio y video sencillos.
  • SoundPool: reproduce sonidos cortos con poca latencia (efectos en juegos).
  • ExoPlayer / Media3: reproductor avanzado de Google para streaming de video y audio.
  • VideoView: componente simple para mostrar videos.
  • CameraX: para tomar fotos y grabar video con la cámara.
  • MediaRecorder: para grabar audio desde el micrófono.
  • ObjectAnimator, MotionLayout y la API de animaciones de Compose: para crear animaciones.
  • Lottie: reproduce animaciones vectoriales en JSON.
  • En iOS: AVFoundation / AVPlayer (audio y video) y Core Animation.
Ejemplo 1: reproducir un sonido con MediaPlayer
kotlin
// El archivo está en res/raw/boton.mp3
val reproductor = MediaPlayer.create(this, R.raw.boton)
reproductor.start()

reproductor.setOnCompletionListener {
    it.release()   // liberar memoria al terminar
}
Ejemplo 2: cargar una imagen de internet con Glide
kotlin
Glide.with(this)
    .load("https://ejemplo.com/foto.jpg")
    .placeholder(R.drawable.cargando)
    .into(imageView)
Ejemplo 3: animar un botón
kotlin
ObjectAnimator.ofFloat(boton, "rotation", 0f, 360f).apply {
    duration = 800
    start()
}
