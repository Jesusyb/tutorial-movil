📡 Gestión de sensores

Cómo una app puede usar los sensores del teléfono para saber movimiento, posición o el ambiente.

Contenido

  1. Definición de sensores
  2. Tipos de sensores en dispositivos móviles
  3. Proceso de gestión de sensores

Definición de sensores

Un sensor es un componente que detecta un cambio físico del entorno (movimiento, luz, temperatura, campo magnético, etc.) y lo convierte en datos que el sistema operativo y las aplicaciones pueden leer.

En los dispositivos móviles los sensores pueden ser:

  • De hardware: son componentes físicos dentro del teléfono, como el acelerómetro o el sensor de luz.
  • De software (virtuales): no son físicos; calculan sus datos combinando la información de uno o más sensores de hardware. Por ejemplo, el sensor de gravedad o el de aceleración lineal.

Tipos de sensores en dispositivos móviles

Android agrupa los sensores en tres categorías principales:

CategoríaSensor¿Qué mide?Uso común
MovimientoAcelerómetroAceleración en los ejes X, Y, Z (m/s²), incluida la gravedad.Girar la pantalla, contar pasos, detectar sacudidas.
GiroscopioVelocidad de rotación en cada eje (rad/s).Juegos, realidad aumentada, videos 360°.
Gravedad / Aceleración linealLa gravedad por separado, o la aceleración sin la gravedad (sensores de software).Detección precisa de movimiento.
Vector de rotaciónOrientación del dispositivo en el espacio.Brújulas, mapas, juegos.
AmbientalesLuzIluminación del ambiente (lux).Brillo automático de la pantalla.
Barómetro (presión)Presión del aire (hPa).Calcular altitud, apps del clima.
Temperatura y humedadTemperatura ambiente (°C) y humedad relativa (%).Estaciones meteorológicas (pocos teléfonos los tienen).
PosiciónMagnetómetroCampo magnético terrestre (μT).Brújula digital.
ProximidadDistancia de un objeto a la pantalla (cm).Apagar la pantalla durante una llamada.

Además existen otros sensores y componentes muy usados en las apps: GPS (ubicación), lector de huella y reconocimiento facial (biométricos), cámara, micrófono, NFC y el podómetro (contador de pasos).

Proceso de gestión de sensores

1. Habilitación

  • Se obtiene el administrador de sensores con getSystemService(SENSOR_SERVICE).
  • Se verifica si el dispositivo tiene el sensor con getDefaultSensor(); si regresa null, no existe.
  • Si el sensor lo requiere, se declaran y piden permisos (por ejemplo ACTIVITY_RECOGNITION para el contador de pasos o ACCESS_FINE_LOCATION para el GPS).

2. Obtención de información

  • Se implementa la interfaz SensorEventListener.
  • Se registra el listener con registerListener() indicando la frecuencia de lectura (SENSOR_DELAY_NORMAL, SENSOR_DELAY_UI, SENSOR_DELAY_GAME o SENSOR_DELAY_FASTEST).
  • Cada vez que cambia el valor se ejecuta onSensorChanged(), que recibe un SensorEvent con el arreglo values.

3. Procesamiento

  • Se interpretan los valores (por ejemplo values[0], values[1], values[2] para los ejes X, Y, Z).
  • Se aplican filtros para quitar ruido (filtro de paso bajo o paso alto) y umbrales para detectar eventos, como una sacudida.
  • Se actualiza la interfaz o se realiza una acción.
  • Se desregistra el listener en onPause() con unregisterListener() para no gastar batería.
Ejemplo: leer el acelerómetro y detectar una sacudida
kotlin
class MainActivity : AppCompatActivity(), SensorEventListener {

    private lateinit var sensorManager: SensorManager
    private var acelerometro: Sensor? = null

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        // 1. Habilitación
        sensorManager = getSystemService(SENSOR_SERVICE) as SensorManager
        acelerometro = sensorManager.getDefaultSensor(Sensor.TYPE_ACCELEROMETER)

        if (acelerometro == null) {
            Toast.makeText(this, "Este teléfono no tiene acelerómetro", Toast.LENGTH_SHORT).show()
        }
    }

    override fun onResume() {
        super.onResume()
        acelerometro?.also {
            sensorManager.registerListener(this, it, SensorManager.SENSOR_DELAY_NORMAL)
        }
    }

    override fun onPause() {
        super.onPause()
        sensorManager.unregisterListener(this)   // ahorrar batería
    }

    // 2. Obtención
    override fun onSensorChanged(event: SensorEvent) {
        val x = event.values[0]
        val y = event.values[1]
        val z = event.values[2]

        // 3. Procesamiento: fuerza total menos la gravedad
        val fuerza = sqrt(x * x + y * y + z * z) - SensorManager.GRAVITY_EARTH
        if (fuerza > 12) {
            Log.d("Sensor", "¡Sacudida detectada!")
        }
    }

    override fun onAccuracyChanged(sensor: Sensor?, accuracy: Int) { }
}
